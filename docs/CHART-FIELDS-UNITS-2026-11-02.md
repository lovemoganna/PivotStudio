# 图表字段自由选择与显示单位修复 · 2026-11-02

## 复现与根因

用户提供的交易数据包含 21 个字段、1 行源总计、4 行成交明细。本轮在本地独立实例导入该原始样本；回归用例以序号 2–5 明确限定范围，没有自动删除或猜测汇总行。原始账户及订单数据只保存于本地忽略的 artifacts 目录。提交的测试数据是同结构的合成记录，不含用户账户或订单。

1. 图表行列下拉框按推荐角色筛选字段，排除了数值型账户 ID 和其他数值维度；值下拉框只提供数值度量，文本不能用于计数。表格字段选择器原本没有这种限制。
2. 当前行字段不在下拉框选项中时，浏览器会显示第一个选项，导致编辑器视觉上显示“序号”，而配置和实际图表仍按账户 ID 分组。
3. 计数单位在共享格式器中无条件返回“笔”，覆盖单位编辑意图；格式面板只编辑 currency，也没有单独保存计数显示单位。
4. 中文字段名末尾的小写 id 没有被标识符规则覆盖，可能被默认推荐为求和指标。
5. 格式面板只提供 0–2 位小数，虽然引擎和保存格式已支持 0–12 位，无法在该入口完整展示样本的六位均价。

最早失败信号：计数自定义单位断言失败，以及真实浏览器中“行字段”选项缺少“用户主账户id”。修复前日志保存在 `artifacts/chart-fields-units-2026-11-02/reproduce-missing-id.txt`。对照截图使用用户原始附件，不把后来截图误标为修复前。

## 最终修改

- `ChartStudio.jsx`：行列提供全部源字段；值提供全部源字段、记录数及已配置指标。字段推荐仅用于推荐，不作为手动分析权限。已配置指标按指标 ID 绑定，区分同名字段的求和、计数和公式指标；源字段使用共享的默认计算规则，文本默认计数，ID 默认去重计数。
- 样本价格字段专项还复现了原有空状态缺陷：第一个对手账户均价为空，另一个有效，但首系列有效数为零便隐藏整张柱图。普通坐标图改为检查全部实际系列的有效值；空值保留为空，不补零。饼图等依赖主系列的图表不因此改变统计口径。`release.txt` 保留首次失败（6 通过、1 失败、41 未运行）。
- `formatters.js`：显示单位可修改或显式清空。计数使用独立的 `format.countUnit`，避免把源字段的 kg、货币等物理单位继承为计数单位。旧配置未声明计数单位时保留原“笔”显示，兼容已有配置。百分比显示仍遵循百分比口径。
- `FormatModal.jsx`：复用现有“格式与数值”入口，正确读取、编辑计数和非计数单位；清空隐藏显示单位。小数位范围开放至已支持的 0–12 位。
- `viewConfig.js`、`metricCatalog.js`：保留并校验计数单位，使保存、分享和指标定义不丢失设置。
- `fieldSemantics.js`：中文名称末尾的 id/uuid/guid 作为标识符处理；显式数值度量角色和手动聚合选择仍保留。
- 没有修改计算引擎，未推断未知币种，未重新发布线上站点。

## 统计与格式契约

原始测试表及其汇总数值仅保留在本地，不随代码发布。回归验证非空计数包含零、求和保留源精度、价格可以显式显示六位小数。普通平均值不冒充加权平均；未声明的单位保持未知，由用户明确设置。

单位编辑仅改变标签，不进行币种或数量换算。CSV 使用格式化显示；Excel 保留数值及对应数字格式，已在浏览器测试中读取真实下载文件校验。

## 有限修复与回归记录

原版浏览器页面的观察被工具安全策略拒绝，没有绕过该页面访问。后续验证针对独立本地产品实例导入用户提供的 CSV，与用户当前页面的状态隔离；不能声称已检查原 5202 页面。

初版尝试在指标卡片内增加单位输入，8 项原始样本专项通过，但 10 万行 R3 回归稳定发现列字段拖回行区失败。对照未修改源码快照，旧版本同一原始 R3 通过。临时事件探针记录：新增行导致配置区滚动后，按下卡片自动聚焦触发 scrollTop 从 18 回到 0，dragstart 未发生。

三种候选方案的结果均保留：内联输入引入回归；让 SVG 不接收指针未解决；聚焦时指定 preventScroll 也未解决。停止扩展该交互，回退内联输入及两个拖拽尝试，完整恢复原 `PivotConfigPanel.jsx`；单位编辑集中复用原格式面板。未改动 R3 拖拽步骤、真实原生操作或通过标准，没有用强制点击或按钮替代拖拽。

临时诊断代码已从产品和测试目录删除。失败与对照证据在 artifacts 下的 `validated`、`drag-recheck`、`drag-baseline`、`drag-probe`、`drag-pointer`、`drag-pointer-baseline`、`drag-focus`、`drag-fixed`、`drag-focus-fixed` 日志和 traces 中保留。不能把被放弃的内联编辑描述为已交付功能。
