# PivotStudio 功能真实状态（2026-10-20）

| 能力 | 实现和验证状态 |
| --- | --- |
| CSV/Excel 导入 | 本地已实现。CSV 支持跨字节 UTF-8、引号和多行字段；真实 Chromium 上传并核对透视总计 |
| 多维透视 | 已实现；聚合、筛选、分组单元测试。部分复杂边界仍待扩展 |
| 15 种图表 | 当前浏览器可切换全部 15 种；代表图形有截图。完整数值核算和所有钻取流程尚未验收 |
| 真实 XLSX 导出 | 从透视矩阵生成完整数值行与平铺表头，支持数值计算；真实浏览器下载后 Node xlsx 重读并核对 300。**不保留复杂合并表头** |
| CSV/明细导出 | 已实现；完整组数据、转义引号及防公式注入。真实 CSV 文件浏览器下载、内容核对已通过 |
| 柱形图正确性 | 绝对值柱/条形轴以零为基点；用 100K 合成数据浏览器核验。标签挤压自动抑制 |
| 直方图 | 过滤空白/无效数值，频数轴从零起；需扩大边界用例 |
| 100K 合成压力测试 | Node CI 正确总计 5,000,050,000，~104–112ms，额外堆 ~18MiB；Chromium UI ~185–203ms。仅报告该 CI 样本，不能泛化为产品保证 |
| 公共 Google Sheets CSV | fetch 真实数据，受 CORS/公开权限影响；尚未在部署站点验证特定公共表 |
| 数据库 SQL 代理 | **未实现**，界面明示不可用 |
| DuckDB 实际执行 | **未实现**；提供 SQL 模板，但透视计算在浏览器 JavaScript 端 |
| 私有 Google OAuth | **未实现** |
| 工作区快照 | 浏览器本地存储，失效/缺数据快照会阻止恢复；无云端同步 |
| 分享和角色 | Base64 配置分享（非加密），按数据集和字段核验，角色仅 UI 演示不是认证 |
| 移动/桌面 | Chromium 320/390/768/1440/1920px 初步检验；无完整设备矩阵证书 |
| 无障碍 | 已有多处弹窗焦点管理、标签/键盘分栏/只读提示；完整 WCAG 2.2 合规评估未实施 |

**统一原则：** 构建通过、按钮显示或截图美观不能替代实际数据、文件下载及业务流程验证。剩余问题和停止条件详见 [DESIGN_QUALITY_REVIEW.md](./DESIGN_QUALITY_REVIEW.md)。
