# PivotStudio 功能能力与验证状态（2026-10-20）

| 能力 | 当前实现 | 已验证范围及限制 |
| --- | --- | --- |
| 本地 CSV / Excel 导入 | 已实现 | CSV 已通过真实 Chromium 导入 33 行、12 字段和透视初始化；Excel 文件上传分支仍需专项实测 |
| 透视聚合 | 已实现 | SUM/AVG/MIN/MAX/COUNT/DISTINCT 和分组筛选单元测试；更多复杂口径仍需测试 |
| 图表与下钻 | 已实现 | 浏览器检查默认图、移动端图表可达与表图切换；全部图种和下钻流程尚未回归 |
| CSV 导出 | 已实现 | 浏览器真实下载和文件解析通过，7 行透视结果与 XLSX 行数一致；已测试公式型字符串保护 |
| Excel 导出 | 已实现 | 浏览器真实 XLSX 下载解析通过，7 行结果；大表全量平铺表头，小表保留 DOM 合并表头；复杂工作簿往返待验证 |
| SVG / PNG / 浏览器打印 | 已实现 | 一般图表 SVG，漏斗图 PNG，PDF 由打印窗口处理；真实文件回归待补 |
| Google Sheets 公开 CSV | 真实 fetch | 受公开权限与跨域限制；部署地址端到端连接待测 |
| SQL 代理 | 未实现 | 已移除虚假连接反馈，界面如实标记不可用 |
| DuckDB 引擎 | 未实现 | 只有 SQL 模板；运行计算仍是浏览器 JavaScript |
| 100K 合成数据 | 测试入口 | 并非性能认证；缺少运行时间、内存与阻塞的实际验收 |
| 工作区 | 浏览器本地持久化 | 无服务端存储及跨设备同步 |
| 分享与角色 | 部分 / 演示 | Base64 仅分享配置，角色非真实认证和授权 |
| 响应式工作台 | 已改进并做烟测 | Chromium 320/390/768/1024/1440/1920px 视口与截图；低端移动设备尚未实测 |
| 弹窗可访问性 | 部分修复 | 已覆盖主要弹窗焦点约束、键盘 Escape 和初始焦点；屏幕阅读器审查未完成 |

## 当前优先缺口

必须继续检查复杂真实数据流、全类型图表、100K 性能和 UI 阻塞、键盘导航、阅读器适配，以及与高水平同类作品的逐屏比较。详见 `DESIGN_QUALITY_REVIEW.md`。

验收原则：CI 成功并不自动代表功能全部完成或达到获奖品质。每项完成结论均需要明确的实际运行证据。


## 2026-10-20 新增实测证据

GitHub Actions 的 Chromium 烟测还覆盖 15 种图表切换、CSV→XLSX/CSV 真正下载与结果解析、主要弹窗键盘操作及 100K 浏览器加载。Node 100K 透视约 202ms（堆约 30MB）；Chromium 100K 测试约 393ms，存在约 237ms 长任务。均为单次 CI 环境数据，不构成生产性能承诺。详情见 DESIGN_QUALITY_REVIEW.md。
