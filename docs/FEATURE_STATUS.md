# PivotStudio 功能与验证范围

基线 `5100d97`，R1–R8 逐项验收记录见 [R1-R8-ACCEPTANCE.md](R1-R8-ACCEPTANCE.md)。

| 能力 | 当前实现 | 验证与边界 |
|---|---|---|
| 本地导入 | CSV/TSV/TXT、XLS/XLSX；Worker 解析/转换 | UTF-8/GBK、四种分隔符、表头检测和人工纠正；前 20 行预览；表头判断存在歧义，须人工确认 |
| 本地计算 | Worker 聚合、字段统计、筛选值和明细请求 | 支持进度与终止取消；不再回退到主线程计算业务数据 |
| 透视配置 | 行/列/值/筛选，求和、计数、平均、去重等及占比 | 保留原有分组、小计、计算指标、30 步撤销重做；跨区移动为一次历史操作 |
| 图表联动 | 图表下钻、表格高亮与双击明细 | 新增 SVG 热力图，保留原有 15 种图表和可选全局筛选联动 |
| 视图 | 本机命名保存、恢复、删除 | 分享链接只包含配置，位于 URL fragment；不包含数据行；接收方须自己导入数据 |
| 表格导出 | XLSX 数值及格式、CSV 格式化数值 | 从完整结果而非虚拟 DOM 生成，遵循筛选/排序；平铺表头，不保留 Excel 合并表头 |
| 图像导出 | 图表 PNG、SVG | 内联样式、背景和图例；包含自绘热力图与漏斗图；PNG 单边限制 8192 像素 |
| 移动与外观 | 横向滚动、固定行表头、系统/手动主题、中英文 | 本机偏好持久化；字段名与原始数据不翻译 |
| 异常处理 | 持续显示错误及建议、渲染保护、Worker 重试 | 空文件、格式错误、缺字段警告、存储失败、Worker 错误和稀疏矩阵内存保护 |
| 外部数据 | 公开 Google Sheets CSV 读取 | 仅导入时快照；公开权限/CORS 失败明确提示；无私有 OAuth、定时同步或数据上传 |
| SQL / DuckDB | 模板，未执行 | 无数据库连接、后端代理或 DuckDB runtime |

内存保护：按浏览器可报告的设备内存设置 32–256 MB 输入文件保护上限（无法报告时为 128 MB），最多 50,000 个分组节点、500,000 个结果单元格/交叉桶。热力图显示前 200 个行分组；筛选列表显示前 200 个匹配值，支持搜索且全选仍覆盖完整集合。限制触发时提示减少字段、分组或拆分文件。浏览器/操作系统强制杀死进程无法由 JavaScript 拦截。

性能数字仅代表记录中对应数据形状与测试设备。行数相同的高基数组合可能耗时、耗内存更多；不将单次测试视为所有设备上的 SLA。WebKit 自动化也不等于真实 iPhone/Safari 验证。
