# PivotStudio 深度审查 · 2026-10-22

本轮沿“导入 → 理解字段 → 构建 → 查看结果 → 核对原始记录并解释结果”检查真实运行版本。代表性 CSV/Excel 输入均为明确标注的合成验证数据，用于校验真实解析、Worker 计算、图表、筛选、下钻和导出，不作为业务分析结论。

## 五步实际任务

1. **导入**：CSV 解析预览内校准数值类型，保留空值及无法解析的原值。
2. **理解字段**：点击或键盘打开字段分布，查看非空比例、不同值、数值有效数、缺失和原始异常样本。
3. **构建分析**：从字段分布直接添加指标，再按分类字段分组，无需拖拽。
4. **查看与解释**：真实零为 0，无计算依据为“-”；展开计算依据，核对当前筛选下的有效样本和分母。
5. **回查与恢复**：从异常结果查看原始记录；过滤无数值组时明确提示；重置筛选恢复分析；导出 Excel 并重新读取检查。

## 边界、保留理由与未验证内容

- 既有工作区若在旧导入逻辑中已把异常原值转为 null、或把布尔缺失转为 false，不能从转换后的值恢复原文。需要重新导入源文件；本轮没有猜测或批量重写用户历史数据。
- 没有真人新手参与；不能将自动化通过当作真人已经理解分析方法。未执行真实屏幕阅读器测试，axe 不能证明完整 WCAG 合规。
- 字段名不能确定业务分母、加权平均、因果关系或阶段转化关系。这些需要实际业务定义；不自动生成业务结论。
- 数据集配置记忆在当前打开会话内验证。工作区持久化原有路径继续回归，但多数据集独立历史跨刷新保存未新增承诺。
- 旧保存视图如果将特殊保留字符的原始分组键保存为折叠/排序目标，修复后可能回到展开或未排序状态。原始数据、字段筛选值与普通分组键保留；不为恢复一个有歧义的旧键重新制造合并错误。
- 初次多数据集观察在导入归一化尚未完成时读取了旧界面，未把该瞬时读数作为一个单独的计算错配缺陷。稳定回归明确等待导入弹窗关闭、完成计算并核对目标值。
- 尚待独立验证的假设：负值占比图的适用性提示、跨年份小时/分钟分组的预期含义、全部业务类型的自动指标建议。本轮没有将代码阅读假设包装成已确认并已修复的缺陷。
- P2 保留：极长指标名在部分图例中仍可能截断，完整字段可在字段分布和计算依据查看。没有为本轮计算正确性修复重排全部图表；图例布局需另行定向验证。

## 停止原则

停止于本轮有证据的数据正确性问题和入门路径改进完成实际回归；不以增加功能或文案数量继续扩展范围。对用户认知是否改善的进一步结论，需要真人任务观察。本报告不宣称产品已全面成熟或达到奖项标准。
