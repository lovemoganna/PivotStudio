# UI Quality Loop · 2026-10-23

本轮保留整体设计、技术栈与此前未提交内容，修复指标中心及共享计算、保存、模态和主题的实际问题。完整复现、前后截图、原始结果、修改清单及保留项见 [验收报告](../../outputs/quality-loop-2026-10-23/验收报告.md)、[前后对比](../../outputs/quality-loop-2026-10-23/前后对比.html) 和 [本轮补丁](../../outputs/quality-loop-2026-10-23/本轮修改.patch)。

主要结果：

- 真实列“记录数”的 SUM 不再被当成行数；无同名真实列时保留旧虚拟别名。两行为 10、20 的示例从 2.0 修正为 30.0。
- 共享/保存保留构建模式、常数和分类；历史公式缺少元数据时按原表达式编辑。折算结果 3.0 不再因重新保存变成 150.0。
- 含方括号的字段使用公共引用转义；指标 JSON 整批校验，错误不会退出工作台，合法旧格式可继续导入；导入遵循只读状态。
- 第五个及后续 KPI 使用真实总计；外部新建/编辑入口正确切换；使用中定义先停用再删除，不再假报成功；复制失败有真实反馈。
- 公共弹窗在绘制前注册键盘和焦点，消除早期 Escape 间隙；启动时核对当前系统主题；手机指南可键盘滚动。
- 长函数说明正常换行，原生选择器被约束在 KPI 卡片内，避免 WebKit 越界和相邻卡片遮挡。
