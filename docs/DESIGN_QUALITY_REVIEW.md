# PivotStudio 全局设计质量审查

日期：2026-10-20。初始基线：`8a9eb40`。本记录以已提交源码、GitHub Actions 构建日志、真实 Chromium 交互测试及桌面/平板/移动端截图为证据。

## 质量目标与界限

以 Awwwards、The Webby Awards、FWA 中优秀交互式数据产品的综合完成度为比较目标，不宣称已经获奖或达到该等级。Webby 官方评审涵盖内容、结构及导航、视觉、功能、互动、创新和整体体验：https://www.webbyawards.com/judging-criteria/

不能通过仅改变颜色、圆角、阴影，或仅让 CI 通过，来替代全局设计质量验收。保留稳定的 Monokai 视觉语言和已运行的分析功能。

## 已验证范围

GitHub Actions 运行 `npm ci`、`npm test`、`npm run build` 和真实 Chromium 烟测。浏览器视口覆盖 390×844、768×900、1440×900。检查首屏横向溢出、表和图显示、表图模式切换、移动字段与分析配置展开、键盘分栏、未实现 SQL 的真实状态提示、弹窗焦点与 Escape、明暗主题切换、移动端图表通过正常滚动可达及图表横轴密度。截图保存在对应 CI workflow 的 `pivotstudio-browser-evidence` artifact。

## 当前仍未通过的最终验收项

1. 尚未实施全面的真实业务数据上传、复杂透视组合、所有图表类型、文件导出后重新导入的浏览器端到端验收。
2. 100,000 行性能、内存、长任务阻塞和极端数据规模未建立量化指标；JavaScript 仍在主线程执行。
3. 尚未完成与真实获奖级同类作品逐屏直接比较、专业评委级评分、完整对比证据。
4. 高密度专业数据界面仍有小字号、控件密度、窄屏深层操作复杂性；还需逐屏检查。
5. 部分弹窗仍需焦点陷阱、完整键盘可达性及屏幕阅读器测试，不能宣称完整无障碍合规。
6. 私有 Google Sheets、SQL 代理、DuckDB 实际执行、跨设备工作区协作仍未实现；参见 `FEATURE_STATUS.md`。

## 不可跳过的后续验收

每次变更重新执行整个已建浏览器烟测、单元测试、构建，比较真实桌面、平板、移动端截图；新增问题须先记录证据，再最小修复。所有完整性和性能主张必须用执行结果证明。只有功能、视觉、交互、响应式、细节和整体作品的明显短板均被证据排除，才可以宣布达到高水平奖项竞争标准。目前不能宣布完成。


## 第二阶段：功能可靠性与全局设计复核（2026-10-20）

### 已验证的闭环

1. 已清理重复 CSS 声明，统一焦点、触控和工具栏滚动；六种视口宽度（320、390、768、1024、1440、1920px）均进入真实 Chromium 断言并生成截图。
2. 已改为在平板纵向展示字段与分析配置，并在切换视口时重置滚动位置，避免用错误截图评价响应式首屏。
3. 已修复 CSV 分块 UTF-8 多字节截断、多余字段静默丢弃；明确空值与数值 0 的区别；下钻明细的 CSV 导出复用公式型字符串安全转义。
4. 已实测浏览器导入本仓库 CSV（33 行、12 字段），在页面初始化透视，再真实下载并解析 XLSX 与 CSV；二者各有 7 行结果。并非仅靠按钮或成功提示判断。
5. 已验证页面可切换声明的全部 15 种图表，弹窗具备初始焦点、Escape 关闭与统一焦点约束；透视表列排序和选定数据单元格提供键盘操作。
6. 已减少图表类型和演示分析视角的常驻控件，删除点阵视觉噪声，并将真实分析/导出操作排在演示功能之前。所有原功能仍可通过按需展开或原入口使用。

### 可复核性能数据（一次 GitHub CI 测试，不是生产 SLA）

Node 环境下，100,000 行合成数据透视计算约 202ms，堆内存约 30MB、RSS 约 103MB，汇总额通过独立校验。该值是某次 CI 测量，不代表所有真实数据规模。

Chromium 环境下，100,000 行合成数据从点击生成到数据和图表可用约 393ms，观察到一次 237ms 的主线程长任务。这暴露出 UI 卡顿风险；仍需低端设备和不同数据分布下的性能验证，不能当作“性能无短板”证据。

### 对标框架

2026 Webby Awards 的 Best Data Visualization 官方标准强调以创新、易懂、美观的方式呈现复杂数据：https://winners.webbyawards.com/winners/websites-and-mobile-sites/features-design/best-data-visualization

同一页面列出的 WWF - Blue Corridors、Searching for Birds、Climate TRACE Air pollution 和 Shopify Black Friday 2025 是针对视觉解释和数据叙事的参考作品；它们并不是 PivotStudio 这类通用自助透视工作台的功能一一对应竞争产品。不能以它们的视觉装饰代替透视准确性或用户任务完成率。

Webby Awards 的软件/应用评审还覆盖结构导航、功能、交互、执行、创新及整体体验：https://www.webbyawards.com/judging-criteria/

### 尚未达到的停止条件

目前尚未完成专业评审级跨作品逐屏对照、屏幕阅读器实测、全部筛选及下钻组合、真实 Google Sheets 部署端读取、弱设备上 100K 操作响应及不同数据分布压力验证。设计完成度有所提升，但仍无法以充分证据证明 Awwwards、Webby Awards 或 FWA 获奖级完成度。

下一轮应优先解决上述可复现短板；未发现真实缺陷的稳定区域不做无意义的颜色和装饰调整。
