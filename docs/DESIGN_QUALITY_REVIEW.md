# PivotStudio 全局产品品质评审与回归记录

更新：2026-10-20。基线 `79fdae5`；当前评审以源代码、GitHub Actions 自动化测试、真实 Chromium 桌面/平板/移动端截图和端到端文件往返为依据。本报告记录的是设计竞争目标，而非获奖或第三方认证。

## 官方参照与适用性

Awwwards 官方规则将设计、可用性、创造力、内容分别加权 40%、30%、20%、10%：https://www.awwwards.com/about-evaluation/ 。Webby 官方强调结构导航、视觉、交互、功能和整体体验：https://www.webbyawards.com/judging-criteria 。同类型数据可视化作品参考 2026 年 Webby Winner《WWF — Blue Corridors》（https://winners.webbyawards.com/2026/websites-and-mobile-sites/features-design/best-data-visualization/364937/wwf--blue-corridors）以及 Awwwards Site of the Day《AI in Design Report 2026》（https://www.awwwards.com/sites/ai-in-design-report-2026）。它们偏叙事探索，PivotStudio 偏多维数据工作台，因此比较应侧重清晰、易用、互动与技术执行，不能直接照搬其视觉造型。

W3C WCAG 2.2：https://www.w3.org/TR/WCAG22 。表格的语义和小屏结构参照：https://www.w3.org/WAI/tutorials/tables/tips/ 。

## 代码及真实执行循环

| 轮次 | 全局扫描发现的实际缺陷 | 修复与执行证据 |
| --- | --- | --- |
| 1 | 工作区缺失数据集仍会静默恢复；分享配置可能被用在另一数据集 | 工作区/分享配置校验、源缺失显示受限并禁止恢复；单元测试覆盖匹配、失效和缺字段 |
| 2 | CSV 分块直接逐块解码可能切断 UTF-8 中文字符；明细数值空值伪装为 0 | TextDecoder streaming，空值保留，明细 CSV 公式注入转义、弹窗焦点管理；真实浏览器上传带中文、引号和跨行内容的 CSV，透视总计 300 |
| 3 | Keynote/测试按钮和重复图表切换占用分析主要操作层级 | 演示/内置校验折叠，冗余图表快捷条移除，演示预设仅在演示模式显示；保持 15 图种切换可用，默认静音 |
| 4 | 只读模式字段快捷添加仍可点击；分享参数重复套用；极窄屏控件文字折行 | 编辑控件禁用、标签与触控尺寸改善、URL 参数只在启动处理一次；真实 Chromium 验证只读、320px 和 1920px |
| 5 | 100K 数据需实测，不得用“高性能”按钮代替性能证据 | Node 100,000 行 4 区域、3 年聚合独立核对总计 5,000,050,000，CI 约 104–112ms、堆增量约 18MiB；浏览器合成 UI 约 185–203ms 恢复，**仅该 CI 硬件条件** |
| 6 | 正值绝对柱状图纵轴截断零点，容易误导视觉比较；密集数值标签重叠 | 柱形条形图零基线，ResizeObserver 根据实际尺寸隐藏挤压标签，悬停仍可读；浏览器确认 100K 柱体 6 个，纵轴含 ¥0、标签不重叠 |
| 7 | XLSX 实际导出的金额为带币种符号的文本，不能当数值计算 | 强制从完整透视矩阵生成原生数值单元格和全量行、平铺表头；Chromium 真正下载 XLSX/CSV，Node XLSX 重新读取验证数值 300 和中文维度 |
| 8 | 15 种图表没有完整的实际切换证据；直方图空值被归为 0，频数轴需要从零开始 | Chromium 真实逐一切换 15 图种并留存代表性截图；直方图过滤无效/空白测量并锚定频数零点 |

## 全局品质审查维度

| 维度 | 当前判断 | 实际短板与下一步证据 |
| --- | --- | --- |
| 视觉完成度、品牌与独特性 | 部分通过 | Monokai 风格保持统一但仍为高密度工具界面，与优秀获奖叙事作品的创造性表达不可直接等同 |
| 信息层级、排版与间距 | 改进，未最终通过 | 主次操作已经分离，仍需完整文字缩放和高密度表格检查 |
| 动效与交互 | 部分通过 | 交互控件和状态可测；全场景动效的降低运动模式和输入延迟尚未系统验收 |
| 响应式 | 已做烟测，非全量通过 | 320、390、768、1440、1920px 可见内容及无页面级横向溢出；更多实际设备、缩放和复杂长字段未覆盖 |
| 一致性、可用性与细节精度 | 有证据改善 | 数据来源明确、错误状态清晰、实际导入与文件往返可用；大规模复杂表头和 15 图种的全部视觉细节待查 |
| 功能真实性 | 部分通过 | 公共 CSV 导入、本地透视和导出确有实际路径；SQL 代理、DuckDB 执行、私有 OAuth、服务器协作未实现，不得声称已上线 |
| 综合竞争级完成度 | **尚未通过** | 需要全面真实业务场景、外部交叉评审与实际获奖作品逐屏对照，不能凭自评宣布达标 |

## 验收门禁

每轮必须重新运行全部单元测试、`npm run perf:smoke`、生产构建和 Chromium 浏览器流程，并保留截图与下载文件。Chromium 现覆盖数据导入、真实 XLSX/CSV 下载解析、15 种图表选择、表图切换、只读、键盘分栏、弹窗 Escape、明暗主题、390px 图表可达、极窄屏和 100K 生成。CI 证据在对应 GitHub Actions 的 `pivotstudio-browser-evidence` artifact。

仍须全面验证大数据主线程卡顿、复杂真实数据与全部图表的读数/下钻正确性、长期持久化、键盘及读屏完整无障碍，以及专家对同类高水平作品的独立评审。停止条件尚未达到，不得宣称已获奖或拥有获奖级品质。
