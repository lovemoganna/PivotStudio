# 通用透视分析可信度修复 · 2026-10-28

## 目标与边界

PivotStudio 是面向任意导入数据的透视表和透视图系统。修复依据字段元数据、用户明确选择和配置依赖，不依据零售字段名或内置样本的业务含义。验证输入用于检查机制，不代表真实用户研究。沿用现有 React、计算引擎、导入 Worker 和浏览器测试体系。

工作分支：`codex/analysis-trust-2026-10-28`。保留此前尚未提交的修改。本轮未合并、推送或发布正式产品。

## 发现、修复与验收

### 1. 时间分析：区分分类比较和连续周期

修复前，任意分类都能生成“环比”；按指标排序会改变其值。保存了本轮修改前的源码，并调用修改前后真实计算函数，分类 100、50、200 原先产生 -50%、300%，现在不生成环比线并给出日期配置指导。证据：`artifacts/analysis-trust-2026-10-28/before-after.json`，属于计算证据，不是界面截图。

修复：

- 时间环比、3 期均线要求图表横轴为单一日期维度，支持年、季度、月、日、小时、分钟；日期可以配置在行或列。
- 按时间升序计算；按指标大小排序时阻止生成时间衍生线，并提示恢复默认排序。
- 不跨缺期计算；首期、空值、无有效数值、零基期保持不可计算。3 期均线需要连续三个有效周期，采用各周期聚合值的等权平均。
- 衍生计算读取实际聚合值，不把“补 0 / 前值”显示策略当作观测数据；计算过程保留精度。
- 保留普通图表、分类比较和多指标配置；衍生线使用独立数轴，避免把增长百分比标成第二个指标的单位。

文件：`src/utils/temporalAnalysis.js`、`src/features/pivot/engine/buildChartSpec.js`、`src/features/pivot/components/ChartStudio.jsx`。

### 2. 数值尺度：明确选择，统一底层数值

修复前，仅凭 ResponseRate 等字段名称就启用百分比，35 显示成 3500.0%。修复后，未确认尺度时保留 35.0；明确选择百分数时显示 35.0%。不会依据值是否小于 1 猜测尺度。

修复：

- 导入预览为所有数值字段提供“普通数值 / 百分比小数 / 百分数”选择，并显示实际样本转换示例。
- 35 和 0.35 分别在明确选择后归一为 0.35；源文件和导入预览保留原输入，内存分析数据采用规范化值。
- Excel 数值单元格具有一致的百分比格式时自动识别小数尺度；混合格式不据此推断。
- 继续复用同一套聚合、格式化与导出逻辑，表格、图表、公式和 Excel 使用相同底层值。
- 计算指标库按规范化尺度隔离，避免普通数值和百分比复用同一套旧指标定义；两种百分比输入尺度可共享规范化后的定义。

文件：`src/utils/percentScale.js`、`src/utils/fieldSemantics.js`、`src/utils/metricCatalog.js`、导入 Worker、UploadModal。

验收：20、40 作为百分数导入，平均值显示 30.0%，Excel 数值为 0.3，Excel 格式化后也是 30.0%；切换求和为 60.0%，撤销恢复平均值。

### 3. 配置恢复：明确保存范围，校验后关联

修复前，保存内容只有配置，刷新后数据不恢复；无数据时“更多”入口消失，恢复路径难以发现。旧恢复逻辑还可能把缺字段的配置套到另一份数据。

修复：

- 保存按钮明确为“保存配置”，解释不包含原始数据、需保留源文件；首页存在已保存配置时提供“恢复分析配置”入口。
- 保存与分享附带配置依赖字段的名称、类型、规范化百分比标识，不附带数据行或未使用字段名。
- 恢复前检查行、列、筛选、指标、公式引用及操作数字段；字段顺序不同和无关列变化不阻断恢复。
- 原数据集不可用时明确进入关联流程，可选择已导入的数据集，或暂存配置并重新导入文件。
- 错误导入仍保留数据，但配置维持待关联状态并列出原因；正确数据通过检查后恢复，支持取消等待。
- 同一数据集上的恢复保留配置撤销路径；旧配置缺少源结构时保留兼容入口并提示核对含义。

文件：`src/utils/viewCompatibility.js`、`src/utils/viewConfig.js`、PivotWorkbench、WorkspaceModal、HeaderBar。

验收：保存 → 刷新 → 首页恢复 → 原数据缺失提示 → 错误类型被拦截 → 正确文件恢复；也验证了从已导入数据中显式关联。

## 剩余边界与唯一下一方向

- 周分组目前沿用既有年内周编号，尚未定义可靠的跨年连续周口径；时间衍生分析会明确提示改用支持的粒度。原始日期和星期几也不会被冒充为连续周期。
- 本轮仍只保存配置，不保存数据，不包含完整分析文件或自动备份。类型、尺度匹配不能证明两个文件内容或业务含义一致。
- 旧配置缺少的源元数据无法追溯补齐；部分动态错误文案仍为中文。
- 没有真实用户研究或生产业务数据验证，不能把自动化通过解释为新手任务成功率已经提升。

下一方向仅建议统一字段语义元数据：让单位、尺度、时间口径和允许的聚合方式在导入、字段配置、图表、公式、保存恢复与导出间共享。它能降低任意领域数据的解释歧义，而不依赖某一份演示数据。
