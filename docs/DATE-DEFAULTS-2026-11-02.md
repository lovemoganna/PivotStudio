# 日期初始化与主动分组 · 2026-11-02

## 行为契约

导入后的日期字段默认按原始值展示与分组，保留导入值中的日期、时间及毫秒，不自动汇总成年。用户通过“组”主动选择年、季度、月、周、日、小时、分钟、秒或星期几。已保存配置中明确指定的时间粒度不迁移、不覆盖。月度趋势等明确选择时间口径的预设继续保留其定义。

“原始值”是导入器交给分析引擎的值，不承诺重建 Excel 任意自定义单元格样式。现有日期导入和时区解析规则未在本轮改写。

## 证据与修改

- 修复前，`buildDefaultPivotConfig`、侧栏添加维度和图表快速配置分别写死 `year`。新通用日期用例实际失败；真实浏览器导入带毫秒的合成时间后，初始表格只展示年份，无法找到原始时间。
- `DEFAULT_DATE_GRANULARITY` 统一为 `raw`。初始化、动态一般分析预设、侧栏和图表入口使用该默认值。
- 日期重复添加与字段选择器的禁用判断统一使用 `DATE_GRANULARITIES`，消除只有部分粒度可重复添加的问题。
- 补充 `second` 的分组、维度名称和连续周期索引；秒分组保留完整年月日，支持跨日、跨年比较，拒绝无效秒。
- 分组面板明确说明默认保留原始值，并用 `aria-pressed` 表达当前选择。补充中文与英文文案。

## 回归发现的统计范围问题

原始时间作为列维度后，多列数据使旧的单系列图表问题更明显：同时存在行、列时，饼图、环图、漏斗和瀑布只读取首列，其他时间列被漏掉。通用测试复现了应为两个完整分组总计的结果变为首列数值和空值。

`buildChartSpec` 现在从当前已筛选的完整原始记录重新计算这些图表的行总计，覆盖所有列分组，并在图中标明范围。只有列维度时，列仍作为类别，保留逐时间点的图形。普通柱图、折线和热力图的列系列不合并。

旧环图用例的默认年度列假设已过时；保留“高亮行对应切片、中心数值与占比正确”的断言，预期值改为从全部参与分析记录计算，另新增完全通用的多时间列用例，避免通过修改测试掩盖漏算。
